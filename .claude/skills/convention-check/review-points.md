# 확인 필요 점검 신호

SKILL.md 의 점검 항목 1~8 은 코드만 보고 예 / 아니오가 갈린다(→ 위반).
여기 있는 R1~R9 는 요구사항 · 의도를 알아야 판정이 끝난다(→ 확인 필요). 규칙을 어겼다고 단정하지 않고, 사람에게 물을 질문으로 보고한다.

사용법
- 변경된 줄에 **신호**가 보일 때만 올린다. 신호가 없으면 그 항목은 조용히 넘어간다.
- **예외**에 해당하면 올리지 않는다.
- 한 번에 최대 5건. 넘치면 영향이 큰 순(R1 → R9)으로 자르고 "외 N건"으로 적는다.
- 질문은 예 / 아니오로 답할 수 있게 쓴다. 근거는 CLAUDE.md 조항 또는 기존 코드의 `파일:줄번호`.

---

## R1. 공개 문항 필터 누락
- 신호: `item` 테이블 SQL · JPQL · 파생 쿼리 메서드에 `status` / `ItemStatus` 조건이 없다.
- 예외: 메서드 주석에 "상태와 무관" 등 의도가 적혀 있다(예: `ItemService.getItem` — 관리 화면용).
- 질문: "이 조회는 공개 문항(`ItemStatus.ACTIVE`)만 내보내야 합니까?"
- 근거: CLAUDE.md "공개 문항은 `ItemStatus` 로 판단한다"

## R2. 입력 범위 검증 없음
- 신호: `level` · 페이지 크기 · id 같은 범위가 있는 `@RequestParam` / `@PathVariable` / 요청 필드에 `@Min` · `@Max` ·
  `@Validated` 나 서비스 쪽 범위 검사가 없다.
- 질문: "범위 밖 값(예: `level=9`)을 400 으로 거절해야 합니까, 빈 결과로 둬도 됩니까?"
- 근거: CLAUDE.md "검증 실패는 400 으로 매핑된다"

## R3. 매직 넘버
- 신호: 도메인 의미가 있는 숫자 리터럴(난이도 1 · 5, 페이지 크기 20, 재시도 횟수 등)이 상수 없이 쓰였다.
- 예외: 0 · 1 을 인덱스 · 증감에 쓴 경우, 테스트 코드의 기대값.
- 질문: "`5` 는 난이도 상한입니까? 이름 붙인 상수(`MAX_LEVEL`)로 빼도 됩니까?"

## R4. 트랜잭션 경계
- 신호: 조회만 하는 새 서비스 메서드에 `readOnly = true` 가 없다(클래스 레벨 포함) / `@Transactional` 안에
  외부 HTTP 호출 · DB 와 무관한 긴 반복(`ReportService.sign` 같은 것)이 있다.
- 질문: "이 반복 · 호출을 트랜잭션 밖으로 옮길 수 있습니까?" (커넥션 풀 최대 5 · 대기 3초라 오래 쥐면 고갈된다)

## R5. 지연 로딩 · N+1
- 신호: 반복문 안에서 리포지토리를 호출한다 / 엔티티의 LAZY 연관(`getUnit()`, `getTags()`)을
  `@EntityGraph` · fetch join 없이 서비스 밖이나 반복문에서 읽는다(OSIV 꺼짐).
- 질문: "목록 크기만큼 쿼리가 나가도 됩니까? `@EntityGraph` 로 한 번에 가져올까요?"

## R6. 로그의 개인 · 비밀 정보
- 신호: 로그 인자에 `studentId` · `email` · `token` · `STU-` 가 들어갈 수 있는 변수가 있다.
- 질문: "이 값이 학생 식별자 · 이메일 · 토큰일 수 있습니까? 마스킹하거나 빼도 됩니까?"
- 근거: CLAUDE.md "로그 메시지에 학생 식별자 · 이메일 · 토큰 값을 넣지 않는다"

## R7. 기존 응답 계약 변경
- 신호: 기존 엔드포인트의 `*Response` record 필드 이름 · 타입 · 순서가 바뀌었다.
- 질문: "`characterization/` 스냅샷과 `modern/web/src/api/types.ts` 도 함께 맞춰야 합니까?"
- 근거: CLAUDE.md "응답 타입의 필드명은 `*Response` record 필드명과 같다", characterization 은 고치지 않는다

## R8. 다른 도메인 경계
- 신호: `com.example.item` 코드가 `com.example.assignment` 의 클래스를 import 한다(또는 반대).
- 예외: 상대 도메인의 `*Service` · `*Response` 만 쓰는 경우는 규칙대로다.
- 질문: "이 데이터는 상대 도메인 `*Service` 를 거쳐 읽어야 하지 않습니까?"

## R9. 요청 범위 밖 변경
- 신호: 변경 파일 중 다른 변경과 기능상 연결이 보이지 않는 파일(포맷팅 · import 정리만 된 파일 등)이 있다.
- 질문: "`<파일>` 변경도 이번 커밋에 넣을 의도입니까?"
