## 심화 4 · 로그가 부족할 때 (`app-timeout.log` 하나만 준 새 세션)
- 잘한 점: "클라이언트 관측만으로 세운 가설, 확정 원인 아님"이라고 밝히고, 서버 · DB 로그 · deadlock graph 를 추가 자료로 요구했다.
- 단정한 곳: 데드락 상대를 로그에 없이 "report 와 aggregate 가 서로 교착 상대로 보임"이라고 썼고, 잠금 순서와 무관한 READ COMMITTED SNAPSHOT 을 수정안에 넣었다.
- 마스킹 누출: `교사A(kim)` 처럼 별칭 옆에 원본 아이디 조각을 붙였다.
- `rca` Skill "하지 말 것"에 더할 문장 후보:
  - "로그에 상대 프로세스 · 쿼리 · 자원이 없으면 교착 상대나 잠금 자원을 추정해 쓰지 않는다. '로그로 확인 불가'로 쓴다."
  - "별칭 옆에 원본 값의 일부(이름 · 아이디 조각 · 끝자리)를 붙이지 않는다."
